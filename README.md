How to use
1.Clone repository: using Git.
2.Run application: using OpenJDK 11, Maven 3+, Spring Boot 2+, and an in-memory SQL database.
3.Test with Postman: by sending POST/GET requests to the configured endpoints.
The application will be available at http://localhost:8080.


API structure:
GET /api/stations/{id}
POST /api/stations/
PATCH /api/stations/{id}
DELETE /api/stations/{id}
GET /api/stations/summary
